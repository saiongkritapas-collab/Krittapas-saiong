### Portfolio style
A simple, clean GitHub portfolio. Each project has its own repository with a README following the Data Analysis Lifecycle, plus charts and a short summary of findings.

### Portfolio checklist
- [x] GitHub account

- [ ] CV / resume

## Part 2: Data Analyst Skills Checklist

| Skill | Entry-level requirement | My level |
|---|---|---|
| Microsoft Excel | Formulas, pivot tables, charts | Intermediate |
| SQL | SELECT, JOIN, GROUP BY | None |
| Statistics | Descriptive stats, regression basics | Intermediate |
| Python or R | pandas, basic plotting | Basic |
| Data visualization | Power BI / Tableau / Excel charts | Basic |
| Data cleaning | Handle missing values and errors | Basic |
| Presentation & communication | Explain results to non-technical people | Intermediate |
| Critical thinking | Ask the right questions, check assumptions | Intermediate |

Entry-level roles focus on Excel, SQL, basic statistics and clear reporting.
Senior roles also expect advanced SQL, Python/R, statistical modelling, automation and stakeholder management.
